Python编程注意问题

Python 是解释型语言。编程时，下面四条规则最容易出错，也最值得学生在入门阶段马上记住。

1
区分大小写
while 与 While 不是同一个东西。关键字大小写写错，程序就会报错。
2
# 开头表示注释
从 # 开始到这一行结束的内容，主要是写给人看的，程序运行时会自动忽略。
3
缩进有语法意义
每行开头的空格或 Tab，不只是为了美观，它表示语句之间的从属关系。
4
语法符号必须用英文符号
程序中的冒号、逗号、括号等要用英文半角形式，例如 : 而不是 ：。
活动 1 · 学会读报错

遇到不懂的错误提示怎么办？

先看最后一行

最后一行往往就是“错误类型”，例如 SyntaxError、NameError、IndentationError。

再看出错位置

报错信息通常会告诉你出错的行号，有时还会给出箭头，帮助你更快定位问题。

不懂时可以借助 AI

把“报错信息 + 相关代码 + 你想做什么”一起发给 AI，会比只发一行英文报错更有效。

但不要完全依赖 AI

课堂测试不能用 AI，所以真正要学会的是：看错误类型、找行号、对照语法，再自己改正。

Python的常量和变量

1. 常量

在程序运行过程中，其值始终不发生变化的量。常见的数值或字符串都可以作为常量出现。

45-30.2001'Hello'

2. 变量

在程序运行过程中，其值可以变化的量。变量由“名字”和“值”组成。

名字：score值：85
课堂提问：执行 score = 60 后，又执行 score = 85，变的是变量的名字，还是变量保存的值？
4.1.2

Python的数据类型：数值

Python 常见的数据类型有 Number、String、List、Tuple、Sets、Dictionary 等。本页重点认识三种数值类型。

int

整型

整数，不带小数部分。例如：18、-3。

float

浮点型

带有小数部分的数。例如：2.5、9.9。

complex

复数

由实部和虚部组成，可以写成 a+bj 的形式。

如果不确定某个数据属于哪一类，可以用 type() 来验证。
4.1.2

String（字符串）与 List（列表）

(2) String（字符串）

字符串是被单引号或双引号括起来的文本。字符串的索引从 0 开始，-1 表示最后一个位置。

text = "Python" text[0] → 'P' text[-1] → 'n'

(3) List（列表）

列表写在方括号 [ ] 中，元素之间用逗号分隔。列表中的元素类型可以不同。

student = ['Li Hua', 16, 92.5, True]
4.1.2

Sets（集合）与 Dictionary（字典）

(4) Sets（集合）

集合是无序且不重复的元素序列，常用来判断成员关系或对数据去重。

(5) Dictionary（字典）

字典是一组“键：值”的配对结构。访问数据时，不是靠位置，而是靠键。

对比记忆：列表靠索引取值，字典靠键取值。
4.1.3

Python的运算符与表达式

在 Python 中，对常量或变量进行运算时所使用的符号，叫做运算符；参与运算的对象，叫做操作数；由运算符和操作数组成的式子，叫做表达式。

a = 3 b = 5 result = (a + b) * 2
操作数：a、b、2运算符：+、*表达式：(a+b)*2

课堂速记

看见“符号”先想：它是让程序做什么事情？
看见“数据”再想：它们是谁在参与运算？
最后再想：这些东西连起来以后，形成了一个怎样的表达式？
4.1.3

三类常用运算符

1. 算术运算符

+-*/%**//

除了常见的加减乘除，学生更需要特别认识：幂运算、整除和求余。

2. 逻辑运算符

andornot

它们用于连接或反转条件，结果只有两种：True 或 False。

3. 关系运算符

>>=<<===!=

用于比较大小或判断是否相等，运算结果也是 True 或 False。

**
2 ** 5 = 32
表示“2 的 5 次方”。这类写法学生往往第一次见，需要重点强调。
//
7 // 3 = 2
表示整除。它只保留整数部分，不保留小数部分。
%
7 % 3 = 1
表示求余，也就是“取余数”。在判断奇偶数时非常常见。
特别提醒：= 表示赋值，== 才表示“是否相等”。
